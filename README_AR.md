# مدينة روما + شخصية Mixamo — Godot 4

## التشغيل
1. فك ضغط الملف بالكامل في مجلد عادي.
2. افتح Godot 4.3 أو أحدث، ثم Import واختر ملف `project.godot`.
3. انتظر انتهاء استيراد ملف FBX والخامات.
4. افتح المشروع واضغط F6 أو F5 لتشغيل المشهد.

## التحكم
- WASD أو الأسهم: الحركة.
- Shift: الركض. Space: القفز. C أو Ctrl: الانحناء.
- زر الفأرة الأيمن مع السحب: تدوير الكاميرا. عجلة الفأرة: تقريب/إبعاد.
- E: تفاعل، R: عودة لنقطة البداية، Esc: تحرير الفأرة.
- على شاشة اللمس تظهر أزرار التحكم حسب إعدادات الشخصية.

## ملاحظات مهمة
- تم وضع نقطة بداية اللاعب مبدئيًا عند (0, 2, 0). قد تحتاج تحريك عقدة Player في `main.tscn` إلى شارع/أرض مناسبة حسب إحداثيات ملف المدينة.
- يقوم `world_setup.gd` بإنشاء تصادمات ثلاثية الأبعاد من مجسمات المدينة عند بدء التشغيل. قد يستغرق ذلك وقتًا مع المدن الكبيرة.
- ملفات الخامات الأصلية مرفقة في `city/textures`. إذا لم تظهر الخامات بعد الاستيراد، راجع إعدادات مواد FBX في Godot واربط الصور يدويًا.
- لم يتمكن بيئة العمل الحالية من تشغيل Godot نفسه؛ لذلك يلزم اختبار فتح المشروع وتشغيله داخل محرر Godot عندك.
